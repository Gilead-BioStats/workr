# Slides (Quarto + revealjs)

This folder contains the slide deck source.

## Preview locally

From the repository root:

- Preview: `quarto preview slides/index.qmd`
- Render: `quarto render slides/index.qmd`

Or from this folder:

- Preview: `quarto preview`
- Render: `quarto render`

Outputs go to `slides/_site/`.
